# Data and code notice

The repository contains no individual participant data.

The diagnostic 2×2 tables are factual aggregate data transcribed from published articles or reconstructed from published event/total information as documented in `data/data_provenance.csv`. Users should cite the original publications when reusing those data.

The analysis scripts written for this audit may be redistributed and modified with attribution. Before public release, the authors should add the software licence they wish to use (for example, MIT for code). No licence statement in this draft repository changes the copyright status of the source publications.
