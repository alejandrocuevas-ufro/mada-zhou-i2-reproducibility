Disponibilidad de datos y código

Los datos agregados 2×2 utilizados para los reanálisis, su procedencia y el código R necesario para reproducir los cálculos están disponibles en Zenodo, doi:10.5281/zenodo.22887677, y en el repositorio de desarrollo https://github.com/alejandrocuevas-ufro/mada-zhou-i2-reproducibility. El archivo incluye scripts para reproducir la implementación del I² de `mada` 0.5.12, reconstruir el estadístico de Zhou–Dendukuri, repetir los análisis publicados y ejecutar la simulación Monte Carlo. También se incluyen la semilla de simulación, las versiones del software y un registro del código de `summary.reitsma()` correspondiente a la versión auditada. No se utilizaron datos individuales de participantes.
