Disponibilidad de datos y código

Los datos agregados 2×2 utilizados para los reanálisis, su procedencia y el código R necesario para reproducir los cálculos están disponibles en https://github.com/alejandrocuevas-ufro/mada-zhou-i2-reproducibility. El repositorio incluye scripts para reproducir la implementación del I² de `mada` 0.5.12, reconstruir el estadístico de Zhou–Dendukuri, repetir los análisis publicados y ejecutar la simulación Monte Carlo. También se incluyen la semilla de simulación, las versiones del software y un registro del código de `summary.reitsma()` correspondiente a la versión auditada. No se utilizaron datos individuales de participantes. La versión asociada al manuscrito será archivada con un identificador permanente antes del envío definitivo.
